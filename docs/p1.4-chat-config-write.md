# p1.4 对话写入全部配置

基线：`local-agent-workbench-p1.3.2`。

## 实现要点

- 扩展 `ProposalKind`：`provider` | `app_settings` | `friend_patch` | `group` | `vault_binding`（保留 skill/mcp/task/friend）
- `workbench_propose` stage 仅 pending；确认整笔落库；取消丢草稿
- Key：stage 时 `vault.stage` 密文进 draft.stagedSecret，卡面 `apiKeyMasked`；确认写入 secrets + 引用；无明文进 messages draft
- `workbench_get_config` 只读摘要（无密钥明文）
- 设置页 `PUT /api/settings` 仍保留；聊天路径不能绕过 ConfirmCard
- **后置**：`session_prefs`（会话模式/推理/模型）
- **好友启停**：Friend 无 enabled 字段，`friend_patch` 若带 enabled 人话拒绝

## API / 工具

- 工具：`workbench_propose`（扩展 enum）、`workbench_get_config`
- HTTP：既有 `POST /api/proposals/:id/confirm|cancel`；配置类 kind 确认时 scope 用 `global`
