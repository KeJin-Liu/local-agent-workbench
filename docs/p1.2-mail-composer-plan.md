### 2.2 计划记录 `planRecords`

```ts
export type PlanStatus = 'awaiting_confirm' | 'executing' | 'done' | 'cancelled' | 'failed'
export type PlanStep = { index: number; title: string; done: boolean; result?: string }
export type PlanRecord = {
  id: string
  conversationId: string
  friendId?: string
  title: string
  filePath: string
  status: PlanStatus
  steps: PlanStep[]
  createdAt: number
  updatedAt: number
}
```

- 默认根目录：`/tmp/agent-workbench/plans/`（测试可注入 `rootDir`）。  
- 文件名：`YYYYMMDD-HHmmss-<短标题>.md`。  
- MD 必含产品要求的七个章节；执行步骤用 `- [ ]` / `- [x]`。

## 3. 计划模式服务（`src/app/plan-mode.ts`）

| API | 行为 |
| --- | --- |
| `buildPlanMarkdown(...)` | 生成含七章节 + `[ ]` 步骤的 MD |
| `draftPlan(...)` | 写盘 + 落 `PlanRecord(awaiting_confirm)`；**不**跑副作用 |
| `confirmStart(id)` | → `executing` |
| `cancel(id)` | → `cancelled` |
| `markStepDone(id, index, result?)` | 仅 `executing`；改同一文件对应行 `[x]` |
| `canRunSideEffects(status)` | `awaiting_confirm` / `cancelled` → false |

编排侧（本阶段可后接）：`chatMode==='plan'` 时先只产出计划；确认前拦截写盘/shell/外发类工具。

系统提示词：来自设置 `planModePrompt`（默认=产品 B3 + 澄清条款）；注入时替换 `{{planPath}}` 为实际文件路径。

## 4. 邮箱工作指令（`src/app/mail-instructions.ts`）

| API | 行为 |
| --- | --- |
| `normalizeMailSettings` / `get` / `update` | 走全局 settings；whitelist trim + lower 比较 |
| `ensureOwnerMailPollTask` | `enabled` 时为群主 upsert 固定 id 任务：`*/10 * * * *`（或按 `pollIntervalMinutes`） |
| `filterWhitelisted` | 非白名单 → skip + 记 processed |
| `processMockInbox(mails)` | 白名单 → 去重 → 调可选 `executeInstruction` → `buildResultSummary`（**禁止**逐步 tool 日志） |
| `MockMailSource` | 内存列表，测白名单/去重；真 IMAP/SMTP 后接同一接口 |

结果邮件形状：成功/失败一句摘要 + 可选产物路径；不含逐步流水。
