# p1.3 会话抽技能

基线：`local-agent-workbench-p1.2`。

## 实现要点

- 「保存为技能」→ 本好友会话多选 sheet → `POST /api/skill-extracts`（注入全局 `skillExtractPrompt`）→ 助手草案 + ConfirmCard「保存为好友技能」
- 确认才 `saveSkillForFriend`；取消不落库；旧本会话步骤 sheet 降为 fallback
- 设置页：抽技能提示词可编辑·恢复默认（与计划提示并列）
- 好友设置：`systemPrompt` 醒目可编辑（空=未设置）；已挂技能可预览步骤
- 不动 p0.4 / p0.8

## API

- `GET /api/friends/:id/skill-sessions?currentConversationId=`
- `POST /api/skill-extracts` `{ targetConversationId, friendId, sourceConversationIds }`
- `POST /api/skill-extracts/:id/confirm` `{ name? }`
- `POST /api/skill-extracts/:id/cancel`
- `PUT /api/settings` 支持 `skillExtractPrompt`
